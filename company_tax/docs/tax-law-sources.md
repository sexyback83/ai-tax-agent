# 세무계산기(company_tax) 참고 자료 조사

> 조사일: 2026-08-19
> 목적: `company_tax` 프로젝트(법인세 등 세무 계산기, tax_agent와 유사한 프레임워크 없는 HTML/CSS/JS 단일 파일 구조 예상)에서 참고할 공식 세법·세무 정보 출처 정리.
> 아직 계산 범위(법인세만 / 상속·증여세 포함 여부)가 확정되지 않았으므로, 법인세·상속세·증여세·부가가치세 관련 출처를 모두 포함했습니다.

## 1. 지정 참고 사이트 3곳

### 1-1. 국가법률정보센터 (law.go.kr)

- **URL**: https://www.law.go.kr/main.html
- **이 프로젝트에서의 용도**: 세법 "원문"의 최종 확인처. 세율, 공제 요건, 과세표준 구간 등 계산 로직에 반영하는 모든 수치는 최종적으로 여기서 조문 원문으로 재확인해야 함.
- **세법 전문 찾는 방법**:
  - 통합검색창에 법률명을 직접 입력 (예: "법인세법", "상속세및증여세법", "소득세법", "부가가치세법")
  - 검색 결과 URL 패턴: `https://www.law.go.kr/lsSc.do?query=법인세법` (법령명 검색)
  - 법령 상세 페이지 URL 패턴: `https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=<번호>` 형태 (예: 법인세법 `lsiSeq=247463`, 법인세법 시행령 `lsId=003608`, 법인세법 시행규칙 `lsiSeq=104152`)
  - 각 법령 페이지에서 **법률 - 시행령 - 시행규칙**이 함께 연결되어 조회 가능 (모법과 하위 법령을 같이 확인 가능)
  - 법 분야별 메뉴에서도 접근 가능: "내국세" 분야에 법인세법·소득세법·상속세및증여세법, 부가가치세는 관련 조세 분야에 분류됨
  - 영문 법령도 제공됨 (예: `viewCls=engLsInfoR` 파라미터) — 참고용
- **주의**: `lsiSeq` 값은 법령 개정 시 최신 조문 버전이 자동 반영되지만, 시행일(효력발생일)이 다른 과거 조문도 함께 조회되므로 반드시 **"시행일자"**를 확인해야 함.

### 1-2. 국세청 (nts.go.kr)

- **URL**: https://www.nts.go.kr/
- **이 프로젝트에서의 용도**: 세법 해석 사례(질의회신, 예규), 세무서식, 고시·공고 확인.
- **구체적으로 유용한 하위 페이지**:
  - 세법해석 질의 안내: 메뉴 경로 `국세정책/제도 > 세법해석 질의 안내` (서면질의제도, 세법해석 사전답변제도, 세법단순상담 안내)
    - `https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2526&cntntsId=7823`
  - 세무서식 통합 검색/다운로드: `국세정책/제도 > 세무서식`
    - `https://www.nts.go.kr/nts/ad/nf/nltFormatApiList.do?mi=40178`
  - 고시·공고·행정예고: `알림·소식 > 고시·공고·행정예고`
  - 개인신고안내(상속세) 세액계산흐름도: `https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2326&cntntsId=7720`
  - 개인신고안내(증여세) 세액계산흐름도: `https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2340&cntntsId=7728`
  - → 상속세·증여세 계산 로직을 만들 때 이 "세액계산흐름도" 페이지가 계산 단계(재산평가 → 공제 → 세율 적용 → 세액공제)를 그림으로 보여주므로 **계산기 로직 설계 시 1차 참고 자료로 매우 유용**함.
  - 국세법령정보시스템 안내 페이지: `https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=13363&cntntsId=109143`
  - 국세상담센터(전화 126): `https://call.nts.go.kr/`

### 1-3. 홈택스 (hometax.go.kr)

- **URL**: https://hometax.go.kr/
- **이 프로젝트에서의 용도**: 실제 온라인 신고 화면 구조·계산 흐름(모의계산)을 참고해 계산기 UI/로직 설계에 참고. 단, 홈택스는 로그인 기반 SPA(웹스퀘어) 구조라 WebFetch로 내부 콘텐츠를 직접 긁어오기 어려움 — 실제 사용 시 브라우저로 직접 접속해 화면을 확인하는 것을 권장.
- **구체적으로 유용한 하위 메뉴**:
  - **모의계산** 서비스: 홈택스 메인 화면 우측 "세금종류별 서비스" 코너에서 접근. 양도소득세, 증여세, 연말정산, 퇴직소득세액, 근로소득세 등 모의계산 제공. **법인세 모의계산은 별도로 제공되지 않는 것으로 확인됨** (법인세는 신고서식 자체 계산에 의존).
  - 증여세 계산기(모바일/전용 화면): `https://teht.hometax.go.kr/websquare/websquare.wq?w2xPath=/ui/rn/a/a/b/c/UTERNAAU41.xml`
  - 손택스(모바일) 모의계산 메뉴: `https://mob.tbht.hometax.go.kr/jsonAction.do?actionId=UTBRNAAU99F001&menuId=6004050100`
  - 홈택스 메인 웹스퀘어 진입점: `https://hometax.go.kr/websquare/websquare.html?w2xPath=/ui/pp/index_pp.xml`
  - **주의사항 (홈택스 자체 고지)**: 모의계산은 일부 항목만 반영한 예상 세액이며, 실제 세액계산과 차이가 날 수 있고 신고·불복 자료로 사용할 수 없음을 명시하고 있음 — 우리 계산기에도 동일한 면책 문구를 반드시 포함해야 함.

## 주의사항

- 이 문서에 기재된 URL·조문번호·세율 수치는 **2026년 8월 19일 조사 시점 기준**이며, `law.go.kr`의 `lsiSeq`/`lsId` 등 내부 식별자는 법령 개정 시 재부여되거나 변경될 수 있습니다.
- 2026년 세제개편안은 이 조사 시점 기준 **입법예고 단계**로, 국회 심의 과정에서 세율·구간·시행일이 달라질 수 있습니다. 실제로 계산 로직에 세율/공제액을 코딩하기 전에는 반드시:
  1. `law.go.kr`에서 해당 법령의 **현재 시행 중인 조문**(시행일자 확인)을 재조회하고,
  2. 개정 법률이 있다면 공포일·시행일을 확인하여 계산기에 "기준일자" 개념을 두고,
  3. 홈택스 모의계산 결과와 직접 대조하여 검증할 것을 권장합니다.
- 이 문서 자체는 법률 자문이 아니며, 실제 서비스에 사용하기 전 세무사 등 전문가의 검토를 받아야 합니다.
