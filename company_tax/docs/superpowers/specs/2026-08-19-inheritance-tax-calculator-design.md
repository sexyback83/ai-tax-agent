# 상속세 계산기 설계 (company_tax 프로젝트 1번 서브프로젝트)

## 배경 및 범위

`company_tax`는 개인·법인 자산가를 대상으로 한 세무계산기 모음 프로젝트다. 우선순위 인터뷰 결과 아래 순서로 8개 계산기를 하나씩 독립 개발하기로 했다:

상속세 → 증여세 → 종부세 → 양도세 → 가업승계 → 법인세 → 급여배당 → 주식증여

이 문서는 그중 **1번, 상속세 계산기**의 설계다.

기존 [tax_agent](https://github.com/sexyback83/tax_agent) 프로젝트(상속·증여세 계산기)가 있지만, company_tax의 상속세 계산기는 **완전히 새로 설계**하며 tax_agent는 스타일/구조 참고 용도로만 사용한다.

### 범위에서 제외한 것
- **가업상속공제**는 이번 상속세 계산기에서 다루지 않는다. 법인 영역 5번 순서인 "가업승계" 서브프로젝트에서 집중적으로 구현한다. ([2026-tax-reform-summary.md](../2026-tax-reform-summary.md)에 개편 내용 정리되어 있음 — 경영기간 요건 10→30년, 공제한도 방식 전면 변경 등, 적용시기 '27.7.1.)
- 8개 계산기의 통합(공통 UI 셸, 탭 구조)은 이번 단계에서 하지 않는다. 우선 독립 파일로 만들고, 8개가 다 완성된 후 통합 여부를 별도로 검토한다.

## 대상 사용자

두 가지 모드를 지원한다:
- **간단 모드**: 자산가 본인이 직접 사용. 상속재산을 부동산/현금/기타로 구분 입력하고 배우자 유무·자녀 수를 입력하면 표준 공제(일괄공제·배우자공제·금융재산상속공제)를 자동 적용해 개산 세액을 보여준다.
- **상세 모드**: 세무사/FC 등 전문가가 상담용으로 사용. 채무, 사전증여재산, 금융채무 등 개별 공제 항목을 직접 입력할 수 있다.

## 아키텍처

프레임워크 없이 순수 HTML/CSS/JS. 계산 로직과 화면을 분리해 계산 로직만 Node.js로 자동 테스트할 수 있게 한다.

```
company_tax/inheritance-tax/
├── calc.js        # 순수 계산 함수 (DOM 의존 없음, Node에서도 동작)
├── index.html     # 입력 폼 + 결과 화면 (간단/상세 모드 토글)
└── calc.test.js   # node calc.test.js 로 실행하는 assert 기반 테스트
```

빌드 도구, 번들러, npm 의존성 없음. `index.html`은 브라우저에서 바로 열면 동작해야 한다.

## 계산 로직 (calc.js)

국세청 상속세 세액계산흐름도 기준. 아래 순서의 순수 함수로 구성한다.

1. **상속재산가액** = 부동산가액 + 현금(금융자산)가액 + 기타자산가액
2. **과세가액** = 상속재산가액 − 비과세재산 − 공과금·장례비용·채무 + 상속개시 10년 이내 사전증여재산(상속인) / 5년 이내(상속인 외)
3. **상속공제** (아래 중 해당 항목 합산)
   - 일괄공제(5억원) vs [기초공제(2억원) + 인적공제(자녀 1인당 5천만원, 미성년자 1천만원×잔여연수, 65세 이상 연로자 5천만원, 장애인 1천만원×기대여명)] 중 **큰 금액** 선택
     - 단, 배우자가 단독상속인인 경우 일괄공제 적용 불가(기초공제+인적공제만 가능)
   - 배우자상속공제 = `min(배우자 실제 상속액, 배우자 법정상속분, 30억원)`, 단 5억원 미만이면 5억원으로 함
   - **금융재산상속공제** = `min(순금융재산 × 20%, 2억원)`, 단 순금융재산의 20%가 2천만원 미만이면 순금융재산 전액(2천만원 한도)
     - 순금융재산 = **현금(금융자산) 입력값** − 금융채무(상세 모드에서만 입력, 간단 모드는 0으로 가정)
     - 부동산·기타자산은 이 공제 대상이 아니다
4. **과세표준** = 과세가액 − 상속공제 합계 (0 미만이면 0)
5. **산출세액** = 과세표준 × 세율 − 누진공제액

   | 과세표준 | 세율 | 누진공제액 |
   |---|---|---|
   | 1억원 이하 | 10% | 0 |
   | 1억원 초과 5억원 이하 | 20% | 1천만원 |
   | 5억원 초과 10억원 이하 | 30% | 6천만원 |
   | 10억원 초과 30억원 이하 | 40% | 1억6천만원 |
   | 30억원 초과 | 50% | 4억6천만원 |

6. **신고세액공제** = 산출세액 × 3% (기한 내 신고 시)
7. **최종 납부세액** = 산출세액 − 신고세액공제

### 간단 모드의 가정
배우자 실제 상속액은 입력받지 않고, **법정상속분대로 분할한다고 가정**해서 배우자상속공제를 계산한다 (배우자:자녀 = 1.5:1). 상세 모드에서는 실제 상속액을 직접 입력받는다.

## 입력 항목

**간단 모드**: 부동산가액, 현금(금융자산)가액, 기타자산가액, 배우자 유무, 자녀 수

**상세 모드**: 위 항목 + 채무, 금융채무(순금융재산 계산용), 장례비용, 사전증여재산, 배우자 실제 상속액, 미성년/장애인/연로자 인적공제 대상자 수

## 에러 처리

- 음수 입력 방지, 필수값 누락 시 안내 메시지
- 배우자상속공제가 법정상속분 또는 30억원 상한을 넘지 않도록 자동 제한
- 과세표준이 0 이하면 세액 0으로 표시 (에러 아님)

## 테스트 계획

`calc.test.js`에서 Node assert로 검증. 최소 시나리오:

**시나리오 1 — 배우자 + 자녀 2명, 상속재산 20억원 (부동산 18억 + 현금 2억 + 기타 0원, 간단 모드, 법정상속분 가정)**

| 항목 | 값 |
|---|---|
| 상속재산가액 | 2,000,000,000 (부동산 1,800,000,000 + 현금 200,000,000) |
| 과세가액 | 2,000,000,000 |
| 일괄공제 | 500,000,000 (2억+인적공제1억=3억보다 큼) |
| 배우자상속공제 | 20억 × 3/7 ≈ 857,142,857 |
| 금융재산상속공제 | min(200,000,000 × 20%, 2억) = 40,000,000 |
| 상속공제 합계 | ≈ 1,397,142,857 |
| 과세표준 | ≈ 602,857,143 (5억초과~10억이하 구간) |
| 산출세액 | 602,857,143 × 30% − 60,000,000 ≈ 120,857,143 |
| 최종 납부세액 (신고세액공제 3% 적용) | ≈ **117,231,429원** |

이 값은 법정 공식으로 직접 계산한 것이며, 홈택스 모의계산으로 사용자가 동일 가정(법정상속분 분할, 부동산 18억/현금 2억)으로 대조 검증하는 것을 권장한다(선택사항, 차단 요건 아님).

추가 시나리오는 구현 단계에서 최소 2~3개 더 추가한다 (예: 배우자 없이 자녀만, 미성년자 포함, 금융재산공제 발생 케이스).

## 주의사항 / 리스크

- 원 단위 반올림 규칙은 실제 법령(상속세 및 증여세법 시행령)의 세부 규정을 구현 시 재확인해야 한다. 이 문서의 계산은 반올림 없이 소수점까지 계산한 근사치다.
- 신고세액공제 3%율은 2019년 이후 고정되어 있으며 2026년 세제개편안에서 상속세 신고세액공제 관련 변경 언급은 없었다([2026-tax-reform-summary.md](../2026-tax-reform-summary.md) 참고). 다만 실제 구현 전 최신 법령(law.go.kr)에서 최종 확인할 것.
- 8개 계산기 통합은 미래 과제로 남겨둠 — 지금은 폴더 네이밍(`company_tax/<세목-영문명>/`)만 일관되게 유지해 나중 통합을 쉽게 한다.
